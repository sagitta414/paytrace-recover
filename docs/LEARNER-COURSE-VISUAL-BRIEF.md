# Learner course view

- **Audience and task:** A sandbox buyer follows a private case link, sees the purchased workshop, and opens the first lesson only after the existing entitlement and protected-content checks pass.
- **Feeling:** Editorial, human, calm.
- **Brand relationship:** PayTrace remains the recovery workspace. The course has a quieter editorial identity so the learner outcome reads as a real destination. The PayTrace customer page links to it; both use the same private customer session and backend course-service check.
- **Composition:** A working classroom leads with the actual lesson: a photographic lesson cover, a focused exercise panel, and a single course-guide rail. On narrow screens the lesson appears before the rail. Purchase status and support remain visible but secondary.
- **Direct entry:** Without a private session, the page shows an editorial workshop introduction and a purchase-entry action. It previews the subject and imagery without exposing the protected exercise.
- **Type and color:** Georgia for course headlines, system sans for controls and reading; charcoal, warm stone, and a restrained forest-green action color. Body remains 16px or larger and controls at least 14px.
- **Visual:** The lesson uses a [photograph by Yuheng Ouyang](https://unsplash.com/photos/the-shadow-of-a-vase-on-a-window-sill-PG0fEMjXlJs), distributed under the [Unsplash License](https://unsplash.com/license), self-hosted, credited in the footer, and chosen to demonstrate the workshop's light-and-shadow exercise. The protected lesson text remains real HTML.
- **Honesty:** Only the implemented lesson appears in the course guide. The protected body is fetched after a verified learner opens the lesson and then arranged as readable exercise steps. Photography illustrates the course; it is not presented as a learner's work. The browser receipt remains an internal evidence event, not a learner completion claim.
- **Motion:** No essential animation. Reduced-motion disables smooth scrolling.
- **Premier studio pass:** The public entry uses a deep forest studio palette against the existing golden window-light photograph. Large ivory and gold serif type is the focal point; a thin index and study caption carry the workshop identity. The photo settles into place once, a light sweep briefly draws attention to the subject, and hover responds to the visitor. The signed-in lesson cover receives the same restrained reveal. No animation blocks navigation, loops indefinitely, or carries essential information; reduced-motion removes these effects.
- **Security and truth:** The page asks the private customer API for case status and fetches lesson text only after a click. It never receives the course-service key or displays a scripted success state. A PayPal sandbox case is labeled as such; sample cases are labeled fictional.
