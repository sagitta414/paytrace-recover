# Frontend clarity update

The merchant dashboard now includes task cards for approval, unfinished verification, and evidence gaps. Each opens the first matching case using the existing case-selection flow. Case review includes a next-owner banner and expandable specialist cards with recorded findings, limitations, and cited evidence. Scripted reviews are labeled; stale reviews do not display actionable specialist findings. Existing merchant approval and backend enforcement remain in place.

The private customer page adds a next-step card, latest-message timestamp, message starters, character counts, and an empty conversation state. Message starters fill the editor only; the customer must send the message. Customer confirmation remains distinct from technical verification, and reopened help takes priority over success messaging.

The merchant desk now adds a customer follow-up inbox with search, a combined timeline, a message preview, waiting-on filters, and an exact approval card. Internal reminders are stored per case in SQLite and appear on the dashboard when due; they never send a customer message. Case pages show timestamps for payment and access source checks. Three launcher links open local sample stories, including a verification failure that requires a separate read-only retry. The Connections page offers operator-gated credential checks for PayPal sandbox, the configured AI model, Render tasks, and email domains. These checks authenticate or read provider metadata; they do not run a checkout, agent analysis, workflow, or email delivery.

The changes are based on main and do not merge the separately reviewed backend branch. No new live payment, agent consultation, email delivery, automatic polling, or production authentication is claimed. Browser rendering could not be checked in the authoring session because no browser surface was available. Review Focus and the private customer page at desktop and mobile widths, including expanded evidence, keyboard navigation, pending message retry, and reopened help.
