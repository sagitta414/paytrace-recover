# PayTrace Recover — UX concept drafts

Generated using the built-in image-generation tool. These are visual concepts, not functioning screens or proof of live integrations. The live site was not changed.

Recommended composition: Recovery Inbox for triage, Evidence Canvas for detailed investigation, Guided Recovery for mobile.

## Implementation corrections

- Use the existing approved brand emblem and consistent agent portraits across all screens.
- Keep root cause unknown when only a timeout is recorded; remove speculative causes and unsupported confidence badges.
- Replace broad claims such as "everything is working" with the exact checks and timestamp.
- Agents propose and explain; approved backend code performs writes.
- Approval checkbox must start unchecked; show the actual rehearsal result before approval.
- Replace generated fixture dates, email addresses, and external-platform names with consistent fictional sample records.
- Treat extra navigation such as Knowledge and Analytics as visual exploration, not committed features.
